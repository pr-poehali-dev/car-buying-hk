# Безопасность сайта avtovykupkhb27.ru

## Реализованные меры защиты

### 1. Защита форм от спама и ботов ✅

#### Honeypot ловушка
- Скрытое поле `website_url` для отлова ботов
- Поле невидимо для пользователей, но боты его заполняют
- При заполнении поля форма не отправляется

#### Лимит отправок
- Максимум 3 заявки в час с одного устройства
- Защита от массовых рассылок спама
- Данные хранятся в localStorage

#### Валидация телефона
- Проверка формата (11 цифр, начало с 7 или 8)
- Блокировка повторяющихся цифр (7777777777)
- Блокировка нереальных префиксов (7000, 7111, 7222, 7999)

#### Таймер заполнения формы
- Минимум 3 секунды на заполнение (защита от автозаполнения)
- Максимум 10 минут (защита от устаревших сессий)

#### Санитизация данных
- Удаление HTML-тегов (<, >)
- Удаление JavaScript кода
- Удаление событий (onclick=, onload=)
- Ограничение длины полей (200 символов)

### 2. HTTP Security Headers ✅

```
X-Frame-Options: SAMEORIGIN - защита от clickjacking атак
X-Content-Type-Options: nosniff - защита от MIME-type sniffing
X-XSS-Protection: 1; mode=block - защита от XSS атак
Referrer-Policy: strict-origin-when-cross-origin - контроль передачи referrer
Permissions-Policy: geolocation=(), microphone=(), camera=() - отключение опасных API
Content-Security-Policy: upgrade-insecure-requests - принудительный HTTPS
```

### 3. Защита контента

- Meta-теги безопасности в HTML
- Защита от MIME sniffing
- Защита от clickjacking
- Автоматическое обновление до HTTPS

### 4. Валидация на уровне кода

**Файл:** `src/utils/formSecurity.ts`

Функции:
- `sanitizeInput()` - очистка ввода от опасных символов
- `validatePhone()` - проверка корректности телефона
- `checkRateLimit()` - проверка лимита отправок
- `validateFormTiming()` - проверка времени заполнения
- `checkHoneypot()` - проверка honeypot поля
- `validateFormData()` - комплексная валидация всей формы

## Рекомендации по дальнейшей защите

### На уровне сервера (требует доступа к хостингу):

1. **SSL/TLS сертификат** - убедитесь что сайт работает только по HTTPS
2. **WAF (Web Application Firewall)** - настройте на уровне Cloudflare/nginx
3. **Rate limiting на сервере** - ограничение запросов по IP
4. **CAPTCHA** - при необходимости добавьте Google reCAPTCHA v3

### Мониторинг:

1. Отслеживайте подозрительные заявки в admin панели
2. Проверяйте логи Яндекс.Метрики на аномалии
3. Мониторьте количество отправок форм
